Backup market data

Kotak Neo Trade API. When the primary broker's quotes fail, live prices come from here for a minute at a time. Only the API access token is needed (Neo app → Invest → Trade API → your application) — it reads quotes and cannot log in or trade. Stored encrypted, never shown again.

With "Kite first", view-only users keep live prices from the backup on days nobody links the market-data account (no live tick stream then; pages refresh by polling, history comes from the bars stored on this server).
